# ADR 0016: Deep-space observatory UI redesign

Status: accepted

Presentation layer only. No API, schema, scientific or routing change; every route, form, filter,
button and the demo/live and red-lamp controls behave as before.

- Design tokens (midnight navy, amber, cyan), Newsreader display, Inter body, IBM Plex Mono metadata.
- New AKASH mark (orbit ring, vertical axis, stellar glint) as an SVG component and favicon.
- Left sidebar shell (a scrolling top rail below 900 px), route settle transition, branded loader.
- Space background: seeded stars (never reshuffled), a few unsynchronised twinkles, tiny pointer
  parallax. Off for touch and `prefers-reduced-motion`; capped at ~30 fps; paused when hidden;
  never takes pointer events.
- Synthetic-case thumbnails and the hero orb are decorative and encode nothing.

Verified: tsc, 80 vitest tests, vite build, screenshots of all routes at 1440 and 390 px with no
console errors or horizontal overflow, and key flows with reduced motion. Not verified: real
browsers other than Chromium, screen readers, live-API mode visuals.

## Motion system (addendum, uncommitted at time of writing)
Tokens: micro 150 ms, ui 240 ms, reveal 560 ms, hero 1100 ms. Transform/opacity/dash-offset only.
- Logo: slow ring drift and occasional glint pulse at idle; hover highlight; a sweep only while real
  work is in flight (`lib/activity.ts`: a submitted investigation, a running pipeline, a lab run).
- Sidebar/mobile rail: one measured indicator that glides to the active link (back/forward, direct
  loads and resizes re-measure).
- Routes: view-transition on the route region (old page settles out), then heading, text, content.
- Pointer depth: far/near star layers, grid and a very faint broad glow, a few px, held still over form
  controls, off for touch and reduced motion.
- Pages: hero sequence, candidate records stagger once (never replayed by filters), sky-map grid/point
  reveal plus hover halo and selection ring, spectrum drawn by clipping the real trace then markers,
  image fade then overlays, model rows and detail, lab scan line and chart reveal.
- Reduced motion collapses every animation and transition to near-instant and removes the glow.
Limits: the old page only fades out on in-app link navigation in browsers with the View Transitions
API; the spectrum reveal is skipped above 20 000 points; checked in Chromium only.

### Hero eclipse (addendum)
The logbook hero orb is a looping solar eclipse (20 s): a yellow sun whose glow and core change intensity on separate periods, a white moon crossing it, a corona at totality, then the moon passes and it repeats. CSS only, transform and opacity only, purely decorative (`aria-hidden`). Under `prefers-reduced-motion` it is a still sun with the moon parked off to the side; the red lamp recolours the sun to red.

### Space imagery (addendum)
Each page opens over a dark, illustrative space scene (`frontend/public/assets/space/`, generated by
`scripts/make_space_assets.py`; see the README there). Scenes are CSS background layers blended with `screen` and
masked to fade into the page, so a missing file leaves the page plain. Small case/candidate thumbnails
(`CaseArt`) are keyed by triage category, never by measurement, and fall back to the older SVG drawing. They are
illustrations: no picture is presented as an observation of a TIC target. The Images page shows a labelled
spiral-galaxy illustration until an image is opened. Reduced motion stops the slow scene drift.

### Signature animations (addendum)
Pipeline constellation (stars light only when a step really finishes; pulse while running; dashed if skipped), a
transit schematic drawn from the measured depth, duration and period (labelled as a schematic), a light curve that
draws itself once when data arrives, evidence rings (same findings as the strip, one ring per channel), a sky
zoom-and-tilt with an arc into the investigation, a spectrum sweep that flashes each detected line as it passes,
growing measurement rings on the Images page, occasional background meteors, a moving rim light on the Models
scene, and a moon whose path varies between eclipse passes. Only transform and opacity are animated; every loop
stops under `prefers-reduced-motion` (verified: no infinite animations running). Nothing animates a result that
was not measured.
